# NEXORA OS

NEXORA OS is an experimental Debian 13 amd64 live desktop. It currently provides a live-only image; an installer and persistence are not included.

## Website

The project website is published with GitHub Pages: https://nexora-os-1.github.io/nexora-os/

## Download and verification

Download `NexoraOS-0.1.0.iso` from the [v0.1.0 GitHub Release](https://github.com/Nexora-OS-1/nexora-os/releases/tag/v0.1.0). Verify the file against `SHA256SUMS.txt` before booting. Expected SHA-256:

`40BFE8B380D93224D88EEB210EE3487270289547E130999D615409DE87AB53A0`

Downloading the ISO does not install it. Test it in a virtual machine first. The website documents the verified boot status and limitations.
